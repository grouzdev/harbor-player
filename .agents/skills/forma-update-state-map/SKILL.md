# Обновить карту состояния

1. Прочитай местные инструкции. При `.forma/pending.json` остановись.
2. Прочитай `.forma/index.md`, `.forma/core/core.md`,
   `.forma/core/update-state-map.md` и `.forma/core/graph.md`.
   Каталог выбран установкой, пути — от корня проекта.
3. Выполни установленную операцию `forma.portable.update-state-map` целиком:
   самостоятельный охват репозитория, объяснение проекта до карточек,
   исправление первого экрана и отдельная проверка всех кратких объяснений.
   Источник процесса — установленный контракт, не отдельная инструкция Forma.
4. Сохраняй ID, историю и основания. Не меняй приложение. Соблюдай явные ограничения;
   секреты, сеть, публикация и перенос в основную копию не разрешаются этим skill.
5. Используй локальную Forma с возможностями контракта. Не скачивай её молча.
   Сообщи видимые начальные карточки, смысловую сверку, охват, точные проверки,
   покрытие объяснений и ограничения. Структура не доказывает понимания проекта.

Не начинай с анкеты о каталогах и командах. Детализация подсистем — отдельная задача.
Если клиент сохранил старый skill в контексте, перечитай этот файл и установленный
контракт; обнаружение обновлённых skills может требовать нового сеанса клиента.
