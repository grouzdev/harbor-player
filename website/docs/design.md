# Design

One vertical composition: name → slogan → description → actions → wide screenshot → three prominent feature blocks → four-stage roadmap. No alternate B composition remains in the current gallery.

Materials originate in src/client/styles/base.css (Soft-metal lounge visual layer around 3039; primary button around 3532). The site retains the actual dark metal palette, edge, noise and inset button highlights. The room is darkened with a #080b0bdf / #080b0bc9 overlay fading to #0d0e0e. No application window sizing or overflow restrictions are copied.

Only Fira Sans Condensed is loaded. The type scale has a large monochrome headline, 20px body text (18px on mobile), and 14px auxiliary text. No mono labels, uppercase captions or decorative numbering.

Download is the sole accent button; GitHub and available Portable are underlined text links. Unreleased is a noninteractive status. The screenshot remains a full-image link with an accessible description but no visible caption or icon. Features are three spacious cards; the roadmap is a two-column desktop grid of four numbered cards, stacking on mobile. Its current stage has an olive treatment, while future stages are marked as planned. Footer: license only.

The layout preserves 16:9 imagery, scales the Russian heading independently and uses adaptive gutters. Keyboard focus and reduced-motion support remain. Local exports and screenshots cover EN/RU at 360, 768 and 1440px.
