# Brief and decisions

Harbor is a music player and organizer for a local music collection. The landing should communicate that immediately and offer Windows download and GitHub.

The approved composition is one vertical page with name, slogan, one-sentence description, actions, screenshot, three feature cards and a four-stage roadmap. No FAQ, news/release-notes link, navigation, language switch, repeated call to action, icons or alternate variants. The footer contains only the license link. The roadmap has no dates: the current Windows release is available now, while playlists, cross-platform support, and a mobile app are plans.

English is default; Russian remains directly accessible at /harbor-player/ru/. Localization dictionaries and metadata remain. The description is still a neutral editorial draft pending the owner's wording.

Use actual app materials, a darker lounge background and only Fira Sans Condensed. Keep the slogan monochrome and reserve the olive accent for the main action. Astro and the independent website project remain unchanged. This stage produces a local page and refreshed snapshots; publication is separate.
