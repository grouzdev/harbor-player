# Список изменений

`changelog.json` включается в интерфейс при сборке и не требует доступа к сети.
Записи идут от новой версии к старой. `version` должна точно совпадать с версией
в `package.json`, включая канал и номер beta.

Поля `added`, `changed`, `fixed` — списки коротких изменений для пользователя.
Пустые группы не отображаются. Необязательное поле `date` — дата публикации
в формате `YYYY-MM-DD`; до публикации дату можно не указывать.

При подготовке релиза добавьте запись с его версией и обновите описание
изменений. Исторические записи не переименовывайте под новую версию.
