## Forma — начало

Перед работой прочитай `.forma/index.md` и `.forma/core/core.md`.
Если контекст ещё не восстановлен, пройди `.forma/core/first-review.md`.
Дальше следуй `.forma/core/workflow.md`; обновляй код, договорённости и проверки вместе.
Для обновления установленного ядра используй `forma-update-core` из `.agents/skills/forma-update-core/SKILL.md`.
Для верхней карты состояния используй skill `forma-update-state-map` из `.agents/skills/forma-update-state-map/SKILL.md`.
Страницы проекта пиши по-русски; имена файлов — английские, lower-kebab-case.
Если есть `.forma/pending.json`, сначала восстанови незавершённый переход Forma.
Существующие инструкции сохраняют силу; конфликты выясняй до действий.
