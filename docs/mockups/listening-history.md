# Пульс: история дизайн-концепций

Название фичи — **Пульс**. Актуальная итерация:
[три облегчённых варианта](pulse.html) · [описание](pulse.md).
Предыдущая объединённая компоновка ниже признана перегруженной и сохранена
для сравнения, не как согласованный финальный дизайн.

[Открыть интерактивный мокап](listening-history.html). Открывается напрямую в
браузере без сборки, сервера и API. Использует шрифты и логотип из репозитория,
не загружает внешние ресурсы. Все данные вымышлены, обложки нарисованы CSS.
Рабочее приложение не изменено.

Статичные превью: [A · Лента](listening-timeline.png),

## Выбранное направление: Пульс + Дневник

[Новый объединённый мокап](listening-pulse-journal.html) ·
[статичное превью](listening-pulse-journal.png).
Первоначальные A/B/C сохранены для сравнения.

- Компактная статистика периода сверху.
- Горизонтальный таймлайн дней слева направо: обложка альбома дня, стопка
  обложек, дата и небольшие столбики времени прослушивания по сессиям.
- Нажатие на день открывает крупную обложку и детали самой длинной сессии.
  Ниже можно выбрать другие альбомные сессии этого дня.
- Справа — рейтинг исполнителей и жанры за весь выбранный период.
  Выбор дня не меняет общую статистику.
- Неделя / месяц меняет диапазон таймлайна и статистику. В месяце есть
  два дня без прослушиваний; они остаются на шкале, без выдуманных альбомов.
- Таймлайн не превращается в вертикальную ленту на узком экране:
  сохраняется горизонтальная прокрутка, кнопки стрелок и управление
  стрелками клавиатуры при фокусе на области таймлайна.

Сессии и их время демонстрационные; дневные суммы складываются в сводку.
Таймлайн показывает альбом самой длинной сессии дня. В рабочей версии
«альбом дня» лучше определять по сумме времени всех его сессий за день.
При выборе обложки нижний демо-плеер не переключается: просмотр истории
не должен прерывать текущее воспроизведение.

## Общая идея режима

Отдельное рабочее пространство, как режим обложки: каталог уступает место
истории, нижний плеер продолжает работать. При выходе фильтры, выделение и
прокрутка каталога должны остаться прежними. Возможная точка входа — кнопка
«История прослушиваний» рядом с переключением режима обложки.

Мокап содержит только представление этого пространства, не реальный переход
из каталога. Верхняя полоска DESIGN LAB служит для сравнения вариантов и не
предлагается как часть продукта. Ссылка слева открывает соседний мокап настроек.

## A · Лента

**Вопрос:** «Что я слушал сегодня и где был тот самый трек?»

- Компактная сводка за период.
- Лента от новых к старым, группировка по дням и сессиям.
- Альбомные блоки вместо сотен одинаковых строк; треки раскрываются внутри.
- Метки «первое прослушивание», «альбом целиком», «вернулся спустя N дней».
- Справа — ритм недели и исполнители, к которым чаще возвращался.

Лучший кандидат для первой версии: полезен даже при небольшой истории.
Потенциальное развитие: поиск в истории и действие «Слушать эту сессию».
Это идеи следующего этапа, в мокапе нет поиска и воспроизведения сессии.

## B · Пульс

**Вопрос:** «Как меняются мои музыкальные привычки?»

- Время прослушивания, число прослушиваний и разнообразие библиотеки.
- Активность по дням, рейтинг исполнителей по времени, доли жанров.
- Открытия: исполнители, впервые появившиеся в истории.
- Недельный и месячный периоды. Май показан до 18 числа; сравнение неполного
  месяца — с таким же интервалом апреля.

Подходит для накопленной истории. Следующее развитие: переключение рейтинга
между исполнителями, альбомами и треками, сравнение двух периодов и календарь
активности. Пустые дни важно отличать от дней до начала сбора данных.

## C · Дневник

**Вопрос:** «Как звучала моя неделя?»

- Крупная обложка, альбом дня, несколько понятных фактов.
- Полка дней: выбор карточки меняет обложку и рассказ.
- Меньше таблиц, больше ощущения личной музыкальной коллекции.
- Альбом дня определяется по фактически прослушанному времени.

Ближе всего к режиму обложки. Хорош как второе представление той же истории,
не замена подробной ленте. Тексты историй в мокапе написаны вручную: генерация
через AI не предполагается. В продукте достаточно детерминированных подписей
по фактам: «альбом целиком», «первое знакомство», «четвёртое прослушивание».

## Что можно попробовать в мокапе

- Кнопки A/B/C; прямые ссылки с `#timeline`, `#pulse`, `#journal`.
- Период «неделя / месяц» меняет сводку, основной график, рейтинги и жанры.
  Лента сохраняет последние два дня; полка — последние пять дней.
  Боковой «ритм недели» намеренно остаётся недельным.
- Раскрытие треков двух сессий в ленте.
- Выбор любого из пяти альбомов в дневнике.
- Кнопка паузы меняет состояние демонстрационного плеера, звук не запускается.
- Адаптивная компоновка для узкого окна; кнопки доступны с клавиатуры.

## Рекомендация

После обсуждения выбран **Пульс + Дневник с горизонтальным таймлайном
и обложками**. Первоначальная рекомендация A оставлена только в истории
обсуждения. Все представления должны использовать одну историю событий,
без отдельных независимых наборов данных для статистики и дневника.

## Правила данных, которые надо согласовать до реализации

1. **Время с музыкой** — фактическое время воспроизведения, без пауз. Перемотка
   вперёд не добавляет прослушанное время, повтор участка добавляет.
2. **Прослушивание** — предлагаемый порог: 50% длительности или 4 минуты,
   что наступит раньше. Короткие треки требуют отдельной проверки границ.
   Активный трек показывать сразу, но не включать в счётчик до порога.
3. **Альбом целиком** — все доступные треки альбома достигли порога в одной
   сессии. Знаменатель берётся из библиотеки; неполные альбомы нужно обозначать.
4. **Сессия** — предлагаемый разрыв: 30 минут без воспроизведения.
   Сессия может включать несколько альбомов; в ленте её можно делить на блоки.
5. **Дни и периоды** — локальный часовой пояс пользователя. Сессия,
   пересекающая полночь, разделяется по дням для статистики.
6. **Жанры** — один основной жанр на прослушивание для суммирования до 100%;
   неизвестный жанр — отдельная категория, не потерянное время.
7. **Приватность** — история локальная, без отправки на сторонние сервисы.
   Нужны отключение сбора, очистка с подтверждением и дата начала истории.
8. **Состояния** — новая установка без данных, отключённый сбор, недостаточно
   истории для сравнения, отсутствующая обложка, удалённый из библиотеки трек.
   Метаданные события следует сохранять, чтобы удаление файла не ломало ленту.

Эти правила — предложения для обсуждения, не реализованная аналитика.
