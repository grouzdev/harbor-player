# Настройки как рабочее пространство

Интерактивный прототип: [settings-panels.html](settings-panels.html).
Открывается напрямую в браузере, без сборки и сервера. Использует логотип и
локальные шрифты из репозитория. Не обращается к API; все операции демонстрационные.

Прототип фиксирует первоначальный трёхпанельный вариант. После согласования
рабочая реализация расширена до четырёх панелей по описанию ниже.

## Режим и панели

- Нажатие логотипа заменяет каталог четырьмя панелями настроек. Повторное нажатие
  возвращает каталог. Это выход из режима, а не закрытие отдельных панелей.
- В режиме настроек верхняя панель содержит только логотип: акцентный силуэт
  и отдельный размытый слой свечения. Никаких дополнительных кнопок выхода.
- Все четыре панели всегда видны, без крестиков, сворачивания и перестановки.
- Каждый вход устанавливает равные ширины. Перетаскивание разделителя изменяет
  две соседние панели; остальные не меняют ширину. Минимальная ширина — 300 px.
- На узком окне сохраняется одна строка с горизонтальной прокруткой.
  Содержимое каждой панели прокручивается по вертикали независимо.
- Разделители доступны с клавиатуры: стрелки меняют ширины, Home сбрасывает
  все четыре к равным, End — до максимума в рабочем приложении.
  Заголовки остаются на месте при прокрутке содержимого.
- Нижний плеер остаётся на месте, воспроизведение не прерывается.

## Перекомпоновка

| Панель | Порядок блоков | Изменение относительно попапа |
| --- | --- | --- |
| Внешний вид | Акцент → фон | HEX в отдельном поле, сохраняется по Enter или выходу из поля. Пять миниатюр без названий из `assets/bg/1.jpg`–`5.jpg`, затем превью и выбор собственного изображения. Ввод пути убран после согласования. |
| Приложение | Сканирование → резервные копии | Подписанные селекты. Ручные запуски друг под другом. Объём копий рядом с очисткой. |
| Версия и обновления | Версия → desktop-обновление → что нового | Компактная вторичная кнопка, статус обновления. Локальный `releases/changelog.json`: текущая версия раскрыта, остальные сворачиваются. |
| История действий | Очистка → журнал от новых к старым | Бывшая кнопка перехода в историю не нужна. Компактные записи, перенос длинных путей, подробности внутри записи, действия рядом с операцией. |

Параметры сохраняются сразу, общей кнопки «Применить» нет.
Фон выбирается через системный выбор файла; защитный лимит поднят до 32 МБ.
Ошибки и состояния загрузки в рабочей реализации размещаются в своём блоке,
а не общей ошибкой в разделе фона.

## Реализация после согласования

1. Выделить содержимое текущих настроек из модальной оболочки в три панели,
   сохранив существующие обработчики внешнего вида, сканирования, резервных копий
   и desktop-обновлений. Номер встроенного фона сохранять в настройках.
2. Выделить журнал из модального окна в четвёртую панель. Сохранить API `/operations`,
   обновление журнала, правила восстановления, повтор незавершённых и безопасную
   очистку. Демонстрационная группировка по дням не меняет данные журнала.
3. Добавить режим настроек в оболочку приложения. Состояние каталога
   (фильтры, выбор, позиции прокрутки, ширины панелей) не сбрасывать при переключении.
4. Переиспользовать текущий механизм изменения ширин, но держать ширины настроек
   отдельно от каталога и сбрасывать их при каждом входе. Не включать эти панели
   в механизм скрытия панелей каталога.
5. Предпросмотр восстановления и подтверждение запуска оставить существующими
   безопасными сценариями. Только настройки и сам журнал перестают быть попапами.
6. Предусмотреть загрузку, пустой журнал, ошибки API, выполняющуюся операцию,
   истёкшие копии и состояния обновления. В web не показывать desktop-действия
   и проверку обновлений, а версию показывать из build-info.
7. Проверить режимы desktop/web, узкое окно, разделители мышью и клавиатурой,
   возврат к неизменённому каталогу, сохранение параметров и непрерывность плеера.

В мокапе выбор цвета меняет акценты и свечение, выбор файла показывает фон
в превью. Селекты интерактивны, но не сохраняются. Сканы, обновление,
восстановление и очистка не затрагивают реальные данные.
