# Тексты песен — попап

[Открыть lyrics.html](lyrics.html). Автономный HTML без сборки и сервера.
Все данные вымышлены. Запросов к LRCLIB, чтения музыки и записи файлов нет;
результаты поиска фиксированы, сохранение имитируется до перезагрузки страницы.

## Решения и источник

Источник — обсуждение с grouzdev в Delta.

- Обычный текст для чтения; без парсинга сайтов, таймкодов и подсветки.
- Основные форматы — MP3 и FLAC.
- После первого мокапа пользователь попросил минималистичный попап
  вместо отдельной панели и запретил статичные поясняющие текстовые лейблы.
  Это правило сохраняется для дальнейшей работы над интерфейсом.
- В макете остаются данные песни, действия, подсказки при наведении
  и доступные имена контролов, без постоянных пояснений.

Попап открывается сразу и повторно кнопкой «Текст» в плеере.
Поиск и редактирование заменяют содержимое этого же попапа.
Запись в файл подтверждается отдельно, при повторной записи — замена.
Escape, крестик и нажатие на затемнение закрывают попап.

LRCLIB остаётся кандидатом, а не утверждённой интеграцией.
Условия показа и сохранения самих текстов не выяснены.
Запись в MP3 `USLT` и FLAC `LYRICS` должна использовать существующий процесс
файловых операций; этот макет поддержку записи не доказывает.
