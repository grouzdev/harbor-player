# Бэклог Harbor Player

Единый список незакрытых рисков, проверок и отложенных работ. Запись здесь
не означает подтверждённый дефект или разрешение на реализацию.
Первый этап Пульса принят пользователем на `0.4.0-beta.2` с перечисленными
ниже ограничениями; это не приёмка signed stable.

## Как вести список

- Добавлять наблюдение, evidence, статус и конкретное условие закрытия.
- Различать дефект, необъяснённый исторический сбой, NOT RUN и пожелание.
- Перед диагностикой определить один сценарий, ожидаемое evidence и условие
  остановки. Не повторять общий набор benchmarks без релевантного изменения.
- После закрытия оставить краткий результат и ссылку на commit/отчёт.
  Не превращать принятие риска в утверждение, что причина исправлена.

## Расширения Пульса — без обещанного срока

- PULSE-09: смена timezone с фоновой пересборкой согласованных поколений.
- PULSE-10: retention/компактация raw-интервалов и GC обложек — только после
  измерений, без удаления используемых ресурсов.
- PULSE-11: экспорт/импорт истории, если появится потребность.
- PULSE-12: политика единственного playback-сеанса между окнами, если нужна.

## Репозиторий и выпуск stable

- RELEASE-01 — NOT RUN: первый фактически подписанный stable-дистрибутив
  и проверка на чистой Windows VM. Существующий workflow не доказывает
  реальную выдачу подписи; см. [политику подписи](code-signing-policy.md)
  и [порядок выпуска](../README.md#публикация-signed-stable).
- DEPS-01 — triage: `npm ci --ignore-scripts` на Feather сообщил 17
  vulnerabilities (11 moderate / 4 high / 2 critical) в дереве зависимостей.
  Оценить актуальный `npm audit`, production/dev scope и применимость;
  не выполнять `audit fix --force` без проверки совместимости.
