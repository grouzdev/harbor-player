# LRCLIB: API и права на тексты

Повторная проверка по просьбе grouzdev в Delta. Это результат чтения публичных
первоисточников, не юридическое заключение и не ответ владельца сервиса.

## Что подтверждено

- [Документация API](https://lrclib.net/docs.txt) прямо допускает анонимный
  доступ пользователей и приложений. Нужны идентификация клиента и соблюдение
  ограничений запросов. Регистрация необязательна.
- При регистрации заявлен документ авторизации API для проверки приложения
  магазинами. Это описание доступа к API; лицензия на произведения из этого
  обещания не следует.
- [MIT-лицензия репозитория](https://github.com/tranxuanthang/lrclib/blob/main/LICENSE)
  относится к Software и сопутствующей документации. Явного распространения
  этой лицензии на тексты песен в проверенных источниках нет.

## Что не подтверждено

В проверенных источниках не найдено явного разрешения от правообладателей
на показ текстов сторонним приложением, постоянное локальное хранение
и встраивание в теги пользовательских аудиофайлов.
Это отсутствие подтверждения, а не доказательство запрета.
Бесплатность и некоммерческий характер приложения сами по себе не решают вопрос.

- [Issue #111, Commercial use](https://github.com/tranxuanthang/lrclib/issues/111):
  вопрос о кешировании и лицензиях открыт. На просмотренной странице
  нет ответа владельца, который устанавливает эти права.
  Мнения участников обсуждения не являются условиями сервиса.
- [PR #74 о юридической документации](https://github.com/tranxuanthang/lrclib/pull/74)
  открыт, а не принят. Предложения правил CONTRIBUTING/DMCA в этом PR
  нельзя выдавать за действующие условия сервиса. Даже политика удаления
  контента сама по себе не лицензирует его использование.

## Как можно дополнительно уточнить условия

Вопросы для письменного уточнения у владельца:

1. Допускается ли показ `plainLyrics` в распространяемом локальном GPL-плеере?
2. Допускаются ли кратковременный кеш и постоянное сохранение выбранного
   пользователем текста на его компьютере?
3. Допускается ли запись текста в MP3 `USLT` и FLAC `LYRICS` по действию пользователя?
4. Какая лицензия на тексты это покрывает и от кого получены соответствующие права?
5. Есть ли требования к атрибуции, срокам хранения, удалению и коммерческому использованию?

По последующему обсуждению с grouzdev отсутствие найденного разрешения
не трактуется как доказательство запрета или обязательный блокер выпуска.
Письменное уточнение — способ уменьшить неопределённость, а не установленная
обязательная процедура. Некоммерческий характер и личное сохранение сами
по себе не дают универсальной юридической гарантии.
Онлайн-поиск не отключён. По отдельному поручению поиск при открытии попапа
без текста и сохранение однозначного результата в теги автоматизированы;
это изменение поведения, а не новый вывод о юридических правах.

Обращения владельцу от имени пользователя, регистрация приложения и публичные
комментарии в GitHub не выполнялись.
