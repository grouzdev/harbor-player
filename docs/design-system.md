# Стандартные контролы

## ValueBubble — баббл значения

`src/client/ValueBubble.tsx` — общий неинтерактивный контрол для короткого
предпросмотра значения в указанной точке. Использует цвета `--panel`, `--text`
и размер текста `--type-caption`, поэтому наследует тему приложения.

Контракт:

- `anchor: { x, y }` — координаты точки в viewport (как `clientX`/`clientY`).
- `children: string` — уже отформатированное значение, например `1:30` или `75%`.
- Вызывающий контрол управляет показом, монтируя или размонтируя баббл.
- Баббл появляется над точкой с отступом 10px. Если сверху нет места —
  снизу. Положение ограничено viewport с полями 8px.
- Рендерится через портал в `document.body`, не обрезается контейнерами
  и не перехватывает мышь, касания или фокус.
- Это предпросмотр, а не меню: внутри нет кнопок и других интерактивных элементов.

## RangeSlider — предпросмотр значения

Для одиночного и двойного `RangeSlider` предусмотрен необязательный
`formatValue: (value: number) => string`. Он включает стандартный `ValueBubble`;
без него поведение слайдера остаётся прежним.

```tsx
<RangeSlider
  min={0}
  max={1}
  step={0.01}
  value={volume}
  ariaLabel="Громкость"
  formatValue={(value) => `${Math.round(value * 100)}%`}
  onChange={setVolume}
/>
```

Значение предпросмотра вычисляется по точке на всей ширине дорожки,
округляется до `step` и ограничивается `min`/`max` — по той же формуле,
что и перетаскивание. Наведение не вызывает `onChange`.

Баббл следует за указателем и остаётся видимым при перетаскивании за пределы
дорожки, показывая ближайшее граничное значение. Скрывается при уходе
указателя (после завершения перетаскивания), отмене жеста, нажатии Escape,
прокрутке или изменении размера окна. Для отключённого слайдера и
touch-ввода предпросмотр не показывается.

Форматтер также задаёт `aria-valuetext` текущего значения для скринридеров.
Значение под курсором не подменяет доступное текущее значение слайдера.

В плеере seek-bar использует общий формат времени `duration`, а volume-bar —
целые проценты. Изменение значения по клику, перетаскиванию или клавиатуре
остаётся ответственностью самого слайдера.
