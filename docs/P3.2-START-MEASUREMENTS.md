# P3.2 — измерения cold start

Дата: 19 сентября 2026 года.

`npm run benchmark:startup` собирает production client и выполняет пять
последовательных запусков Electron с отдельным новым data-каталогом для каждого
измерения. JSON-отчёт сохраняется в неверсируемом
`.test-data/startup-benchmark-*/report.json`.

Граница измерения — от входа в main-process JavaScript до `ready-to-show` и до
первого кадра client shell. Это не измерение создания Windows-процесса, не
измерение загрузки музыкальной коллекции и не универсальная скорость другого
ПК.

| Метрика                      | Медиана | Диапазон пяти запусков |
| ---------------------------- | ------: | ---------------------: |
| Main entry → `ready-to-show` |  909 мс |             860–943 мс |
| Main entry → client shell    |  922 мс |             879–962 мс |

После отложенной загрузки production стартовый JS составляет 485 КБ (146 КБ
gzip), вместо 511 КБ (152 КБ gzip). `AppearanceSettingsDialog` загружается
отдельным чанком 5,9 КБ (2,3 КБ gzip), а `TagOperationDialog`, включая
MusicBrainz workflow, — 22,7 КБ (7,7 КБ gzip). Player, основные панели и
cover mode остались в стартовом bundle.

Числа относятся к срезу на Windows 19 сентября 2026 года; сравнивать между
машинами следует методику и изменения, а не абсолютные миллисекунды.
