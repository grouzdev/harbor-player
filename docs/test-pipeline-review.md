# Разбор и устранение повторов проверок

Источник: grouzdev в Delta попросил изучить автотесты и длительность релизов,
затем разрешил устранить повторную работу, описать схему запусков и прочитать
GitHub Actions через `gh` в режиме read-only. Отправка, запуск remote workflow
и публикация не разрешены.

Уточнения пользователя: единственный пользователь и ПК, единственная рабочая БД
вероятно уже обновлена; историческая миграция нужна скорее для будущего.
Проход клавиатурой всех 1000 альбомов не относится к его обычному использованию.
Предложение агента: рассмотреть их место в расширенном наборе, но в первом
изменении не удалять и не исключать проверки.

## Выбранное изменение

- Варианты npm-команд `:built` используют уже собранный `dist`; обычные
  самодостаточные команды продолжают выполнять build.
- Windows CI: одна полная сборка с typecheck; отдельный browser smoke убран,
  его сценарии остаются в полном E2E. Electron упаковывает тот же build.
- Beta release: одна полная сборка; одна упаковка installer/portable вместо
  отдельного pack и последующего dist. Smoke проверяет unpacked, полученный
  при сборке дистрибутивов, и portable.
- Stable release: убрана повторная компиляция перед упаковкой. Подпись,
  порядок signed artifacts и проверки сохранены.
- Состав тестов, workers, retries, триггеры и независимость CI/release не меняются.
- Карта запусков и ограничения: [карта проверок](testing.md).

Альтернатива — сразу разделить браузеры на jobs — потенциально существенно
сократит ожидание, но требует отдельной проверки изоляции, native-зависимостей
и сохранения артефактов. Перенос доверия с release на результаты CI требует
надёжной привязки к SHA. Оба изменения оставлены для обсуждения.

## Проверка

Локально на Windows, Node 24.20.0, поверх `f0cacc4` с изменениями этой задачи:

- `npm ci --prefer-offline --no-audit --no-fund` — успешно.
- `npm run fixtures`, `npm run verify:tags` — успешно, 7/7 форматов.
  Отчёт изменился только датой; эта побочная правка отменена.
- `npm run format:check`, `npm run lint`, `git diff --check` — успешно.
- `npm test` — 71 файл, 599/599, 135.21 с. Первый запуск вместе с подготовкой
  был остановлен лимитом terminal 120 с; повторный полный запуск с достаточным
  бюджетом завершился успешно. Тайм-ауты самих тестов не менялись.
- `npm run build` — успешно, включая typecheck.
- `npx playwright test --list` — 372 теста в 21 файле, по 186 на браузер.
- Точная новая команда `npm run test:e2e:built` — успешно без исключений
  и retries: Chrome 186/186 (7.6 мин), Edge 186/186 (7.3 мин).
  Vitest и браузеры в этой локальной проверке запускались параллельно;
  это не сопоставимый с CI замер ускорения.
- `npm run desktop:pack:built` → `npm run test:desktop:smoke` — успешно.
- `npm run desktop:dist:built` → `npm run test:desktop:smoke` →
  `npm run test:desktop:smoke:portable` — успешно: installer/portable собраны,
  unpacked из этой сборки и portable прошли smoke.
- `node scripts/verify-release.mjs v0.4.2-beta.3 --channel=beta --artifacts`
  — успешно. Первый локальный вызов без тега отвергнут CLI; повтор выполнен
  с явным тегом. В GitHub workflow тег поступает через `GITHUB_REF_NAME`.
- Оба YAML прочитаны через js-yaml; проверено наличие ровно одного `npm run build`
  в каждом job, полного E2E, отсутствие отдельного browser smoke и порядок
  verify:tags перед build.

Remote CI, SignPath/stable-подпись, установка NSIS поверх прошлой версии и
публикация не выполнялись. Ускорение нового workflow в GitHub пока не измерено.
Коммиты, теги и отправка в origin не выполнялись.
