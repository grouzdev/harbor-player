| ---- | ---------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |

## Следующие этапы

**M5 — автоматические метаданные (частично реализован).** Работают подтверждаемый поиск трека или полного альбома в MusicBrainz, локальный кэш, очередь до одного запроса в секунду, индивидуальные патчи треков и обложки Cover Art Archive с безопасным fallback группы релизов. Следующий шаг — Chromaprint/AcoustID для файлов с недостаточными или неверными исходными тегами.

**M6 — домашняя сеть.** Отдельная настройка сетевого доступа, авторизация, роли «слушать» и «изменять», адаптация интерфейса для небольших экранов. При необходимости отдельная интеграция Jellyfin. Открывать текущий локальный API в сеть без этих изменений нельзя.

**M7 — Windows standalone (первый этап реализован).** Работает Electron shell для Windows x64: backend и tag-writer вынесены в utility processes, повторный запуск показывает существующее окно, закрытие сворачивает приложение в tray, а самостоятельная unpacked-сборка проходит packaged smoke. Проверка на чистой VM без инструментов разработки входит в этап дистрибутивов. Следующие шаги — NSIS/portable, интерфейс обновлений, release pipeline и подписанный stable. Подробности и поэтапный roadmap: `docs/windows-build.md`.

## Известные границы

- База и тесты форматов проверены на Windows, Chrome и Edge. Для macOS/Linux нужны собственные проверки файловой системы, упаковки и браузерных кодеков.
- Альбомы разделяются по библиотеке, расположению, названию, исполнителю альбома и MusicBrainz ID либо году. Папки CD/Disc объединяются с родителем. Неоднозначные или отсутствующие теги могут потребовать ручного исправления; автоматического определения издания нет.
- Источник истины для тегов — файл. Внешний перенос обнаруживается как исчезнувший путь и новый файл при повторном сканировании; сохранение ID гарантируется для переносов через приложение.
- Восстановление не перезаписывает файл, изменённый после операции. Удалённые файлы и резервные копии занимают место до ручного удаления из области восстановления.
- Сканирование перечитывает изменившиеся файлы по размеру и времени изменения. Принудительное обновление перечитывает все теги и обложки. Скорость реальной коллекции зависит от диска, количества папок и размера метаданных.
- Воспроизведение обычное браузерное: без gapless, ASIO, bit-perfect, универсального транскодирования и поддержки DRM.
- Общие папки и ссылки не используются для обхода границ библиотек. Символические ссылки и junction внутри коллекции пропускаются.
- Для записи тегов используется LGPL-библиотека через свой адаптер. Исходники приложения Dopamine не переносились.
