`0.4.2-beta.3` после [[release-0-4-2-beta-2|неуспешных попыток beta.2]].

публикация prerelease через штатный workflow. Прежние теги не перемещаем.

видимой строки после программной прокрутки. Уникальная папка позволяет

Chrome/Edge, по пять повторов с `HARBOR_PLAYER_E2E_CPU_RATE=4`.
