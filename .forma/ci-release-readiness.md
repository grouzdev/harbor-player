# Готовность CI до следующего релизного тега

Источник: grouzdev в Delta поручил исправить все оставшиеся проблемы после
неудачного выпуска beta.3. Согласован общий разбор E2E вместо нового
beta-тега после каждого исправления. Версию и существующие теги не меняем.
Отправка в main и выпуск требуют отдельного подтверждения; сначала проверка
на рабочей ветке.

## Исходные свидетельства

На `a07d7bf` прежние регрессии Пульса и владения SQLite прошли в CI.
Release run `41220287108`: Chrome 170/172, ошибки проверки переноса в плейлист
и Home в режиме обложки. Main run `41220287129`: модульные проверки прошли,
Chrome 171/172, исчез пункт контекстного меню в сценарии файловых операций.
Все три сценария проходят локально без замедления.

## План и критерий

Воспроизвести ошибки через контролируемые задержки/замедление, отделить
неверную синхронизацию тестов от ошибок приложения. Не скрывать проблемы
повторами или повышением тайм-аутов. Сохранять trace/screenshot/report при
падении в CI. Полный набор Chrome и Edge должен запускаться на рабочей
ветке до отправки следующего релизного тега.
