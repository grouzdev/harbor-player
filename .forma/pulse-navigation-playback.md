# Пульс: прокрутка и запуск альбома

## Поручение и границы

Источник — grouzdev в текущем обсуждении Delta: убрать яркую левую полоску
у столбиков, синхронизировать нижнюю ручку с краями истории, открывать первый
вход после запуска справа, запускать альбом двойным кликом. План уточнён
в комментариях и разрешён командой «делай». Повторный вход в пределах запуска
сохраняет позицию. Одиночный клик только выбирает альбом; перетаскивание
ленты не запускает музыку. Слияние, публикация и выпуск сборки не поручены.

## Что изменено

- `src/client/styles/pulse.css`: удалена внутренняя яркая тень выбранного
  сегмента; заливка, рамка обложки и клавиатурный фокус сохранены.
- `src/client/PulseMode.tsx`: ручка использует расстояние прокрутки вместо
  номера дня у левого края. Прямое и обратное преобразование согласованы,
  метки годов привязаны к той же шкале. При отсутствии переполнения ручка
  отключена. Двойной клик передаёт ID конкретного исторического альбома.
- `src/client/App.tsx`, `src/client/Player.tsx`, `src/server/app.ts`:
  новый вариант запроса существующей очереди `{ pulseAlbumId }` использует
  штатный путь запуска с начала и обработки ошибок.
- `src/server/pulse.ts`: исторический UUID разрешается в актуальный ключ
  каталога через связанный доступный трек, затем через известный alias альбома.
  Совпадение названия/исполнителя не используется. При недоступной музыке
  ошибка возникает до создания очереди.

Первый вход справа уже был реализован. Сбой не подтвердился в браузерных
проверках, поэтому логика начального позиционирования не изменялась.
Добавлены проверки холодного входа, повторного входа и перезагрузки страницы.

## Проверки и результат

Проверено на рабочем дереве поверх `0.4.0-beta.2`; в дереве также были
несвязанные изменения исправления кодировки тегов, они не отменялись.

- `npm run build` — успешно, включая проверку типов и desktop-сборку кода.
- `npx playwright test tests/browser/pulse.spec.ts --project=chrome --project=edge`
  — 44/44. Покрыты края, ручка, resize, отсутствие переполнения, восстановление
  позиции, двойной клик по обложке и разным сегментам группы, одиночный клик,
  перетаскивание и запуск реального audio через исторический ID.
- `npm test -- tests/pulse.test.ts tests/pulse-adapter.test.ts tests/pulse-layout.test.ts tests/api.test.ts`
  — 88/88. В lifecycle-проверку добавлены разрешение ID после смены тегов,
  fallback по alias и отказ при недоступном треке/удалённой библиотеке.
- `npm run lint` — успешно.

Первый промежуточный браузерный прогон выявил ошибку нового тестового помощника:
поле API `dayKey` не было преобразовано в `date`. Помощник исправлен,
полный повторный прогон обоих браузеров успешен.

Полный e2e-набор, installer/portable и ручная приёмка Electron не запускались.
Перезагрузка браузерной страницы проверяет сброс состояния UI, но не заменяет
ручную проверку перезапуска установленного приложения.
