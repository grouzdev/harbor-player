# Личная музыкальная коллекция

Harbor Player создают для человека, который хранит музыку на своём компьютере
и хочет одновременно слушать её и поддерживать порядок. Основной сценарий —
подключить разрозненные папки, разобрать загруженное, исправить сведения об альбомах
и перенести понравившееся в коллекцию. Это исходный фокус `concept.md`,
который сохраняется в README и реализации.

Пользователь выбирает папки, жанры, исполнителей и альбомы в соседних панелях.
Из найденных треков запускает очередь, затем продолжает исследовать каталог.
Есть режим обложки, плейлисты и Пульс — локальная история альбомов по дням.
Для порядка в файлах предусмотрены пакетные теги, MusicBrainz и Cover Art Archive,
перенос, удаление, предварительный просмотр и журнал операций с восстановлением.
Доступность восстановления зависит от сохранённых копий и настроек recovery.

## Что существует

React-интерфейс обращается к локальному Fastify-сервису. Сервис сканирует
подключённые папки и хранит каталог, очередь и журналы в SQLite. Electron-оболочка
для Windows запускает тот же backend в utility process; доступны installer
и portable, tray и управляемое пользователем beta-обновление.
Сервер слушает `127.0.0.1`: прослушивание с других устройств не реализовано.

Основная коллекция и история остаются локальными. Поиск метаданных и desktop
update checks используют внешние сервисы по описанным в README и политике правилам;
«локальный» не означает полного отсутствия сетевых функций.

Пульс записывает подтверждённое время воспроизведения, хранит события через
IndexedDB outbox и SQLite, показывает дни и статистику альбома. По текущим
проектным документам первый этап принят пользователем на `0.4.0-beta.2`
с остаточными рисками. Обзор не возобновляет завершённую приёмку.

## Замысел и существенные пробелы

Исходный замысел включает кроссплатформенность и возможный будущий стриминг.
Проверенные проектом Windows-сценарии и наличие переносимого кода не доказывают
готовность других ОС. Gapless, сетевой доступ к библиотеке и AcoustID/Chromaprint
не входят в описанную текущую версию.

Подписанный stable и проверка на чистой Windows VM ещё не подтверждены
в `docs/backlog.md` (RELEASE-01). Для Пульса сохранены исторический timeout,
необъяснённый Edge startup tail, NOT RUN silent worker exit injection и границы
ручной приёмки. Это принятые ограничения беты, а не доказанные исправления.

Отдельный EN/RU-сайт на Astro существует в репозитории. Его roadmap относит
плейлисты к будущему, хотя приложение уже содержит UI, API и тесты плейлистов.
В `website/src/config/release.ts` версия и ссылки installer/portable равны `null`,
канал — `unreleased`; конфигурация не выдаёт ссылки скачивания. Это расхождения
локальных источников; фактический опубликованный сайт и Releases не проверялись.
