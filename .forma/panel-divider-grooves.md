# Тёмные канавки между панелями

## Пожелание и границы

Источник — grouzdev в текущем обсуждении: вертикальные разделители почти
не видны; они должны выглядеть углублением в материале. После плана
пользователь разрешил выполнение («действуй»).

Ожидаемый результат: заметный тёмный шов с теневой стороной и слабым
противоположным кантом. Наведение и перетаскивание выделяют край,
но не превращают канавку в светлую полосу.

## Реализация

В `src/client/styles/base.css` общий непрозрачный градиент задаёт вид
вертикальных разделителей каталога и существующего края боковой панели.
Разделители настроек в `settings-workspace.css` используют тот же градиент.
Для светлой темы предусмотрены отдельные оттенки канавки.
Прежний градиент горизонтального разделителя сохранён отдельно.
Геометрия, область захвата и логика изменения размеров не меняются.

## Проверка

В `tests/browser/panel-dividers.spec.ts` проверяются общие стили каталога,
боковой панели и настроек, сохранение канавки при взаимодействии,
обе темы и независимость горизонтального разделителя.

Проверено:

- `npm run build` — успешно, включая проверку TypeScript.
- Целевой запуск Playwright в Chrome и Edge — 10 успешных проверок:
  новые проверки канавок, сброс ширины двойным щелчком, изменение размеров
  в портретной компоновке и изменение размеров панелей настроек.
- Prettier для изменённых CSS и теста, ESLint для нового теста,
  `git diff --check` — успешно.
- Визуально просмотрены снимки каталога и настроек в тёмной теме:
  швы тёмные и непрерывные, с тонким кантом.

Светлая тема сейчас принудительно отключена приложением; тест проверяет
только сохранённый CSS-вариант через атрибут `data-theme`, не добавляя
переключатель темы. Полный набор e2e и модульных тестов не запускался.

## Уточнение: мягкость и совмещение подсветки

grouzdev попросил смягчить швы размытием и исправить подсветку,
которая занимала только правую часть разделителя.
Резкий кант заменён симметричным плавным переходом от поверхности
к тёмному центру. Подсветка — общая для каталога и настроек размытая
внутренняя тень без горизонтального смещения, по всей ширине шва.
Это не меняет область захвата и не размывает содержимое панелей.
Браузерная проверка дополнена проверками плавного профиля и точного
симметричного свечения при наведении, удержании и фокусе.

Повторно проверено после уточнения:

- `npm run build` — успешно.
- `npx playwright test tests/browser/panel-dividers.spec.ts --project=chrome --project=edge`
  — 4 проверки успешно.
- `npx prettier --check src/client/styles/base.css src/client/styles/settings-workspace.css tests/browser/panel-dividers.spec.ts`,
  `npx eslint tests/browser/panel-dividers.spec.ts --quiet` и `git diff --check`
  — успешно.
- Просмотрен снимок каталога в Chrome в тёмной теме.
  Полный набор тестов повторно не запускался.

## Уточнение: без боковых линий, более удобный захват

grouzdev сообщил, что при наведении мешают тонкие боковые границы,
а в узкую область захвата неприятно целиться.

Внутренняя тень убрана: при наведении осветляется середина плавного
градиента, его края сохраняют цвет поверхности. Рамок и боковых
светлых линий нет. В каталоге и настройках невидимая область захвата
расширена до 16 CSS-пикселей: видимый шов 4 пикселя и по 6 пикселей
с каждой стороны. Видимая ширина и размеры панелей не изменены.

Проверено после этого уточнения:

- `npm run build` — успешно.
- `npx playwright test tests/browser/panel-dividers.spec.ts --project=chrome --project=edge`
  — 4 проверки успешно. Помимо стилей проверено реальное перетаскивание
  с обеих сторон за пределами видимой полосы в каталоге и настройках.
- Prettier для изменённых CSS и теста, ESLint для теста,
  `git diff --check` — успешно.
- Просмотрен снимок каталога при наведении в Chrome в тёмной теме.
  Полный набор тестов не запускался.
