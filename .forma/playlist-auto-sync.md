# Автосборка после обновления библиотеки

Источник: grouzdev сообщил в Delta, что Zenphone собирается после каждого
обновления папки, даже без добавлений. После исследования разрешил реализовать
фикс. Граница задачи — определение изменений и запуск автосборки; без изменения
смысла полного обновления, публикации и слияния.

## Причина и правило

«Обновить» в меню библиотеки отправляет `force: true`. Раньше сканер добавлял
каждый перечитанный трек в список изменённых без сравнения данных.
Быстрое сканирование уже отсекало неизменившиеся файлы, поэтому существующая
регрессия не ловила проблему полного обновления.

Полное обновление по-прежнему перечитывает метаданные. Сканер сравнивает
результат чтения с прежними данными, исключая служебные поля и пользовательские
оценки. Возврат файла с прежними размером и временем восстанавливает доступность.

Перед сканированием, отключением библиотеки или файловой операцией сервис
сохраняет планы автособираемых плейлистов; после сравнивает их с новыми.
План включает исходники, размер и время изменения, итоговые пути и сведения
для предупреждений. Расчёт путей и выбор первого трека при коллизии общие
с самой сборкой. Служебный scanId и метаданные, не меняющие результат,
не запускают задачу и не сбрасывают состояние синхронизации.

Ручная сборка остаётся явной проверкой папки назначения. Изменения исходного
файла определяются по размеру и mtime, как прежде: поиск подмены содержимого
с сохранением обоих признаков не входит в задачу.

## Проверка

Регрессии в `tests/playlist-sync.test.ts`: повторное быстрое и полное обновление
без изменений; новый файл внутри папочной записи и вне неё; исчезновение
и возвращение с прежними файловыми признаками; изменение метаданных без изменения
выходного плана и изменение пути по шаблону. Существующие проверки сохраняют
инкрементальное копирование, защиту чужих файлов и разрешение коллизий.

## Результат

Реализовано в рабочем дереве поверх `52e8d4e`. Проверки:

- `npm test -- tests/playlist-sync.test.ts` — 12 тестов прошли;
- `npm test` — 519 тестов, 66 файлов прошли;
- `npm run typecheck` — прошло;
- `npm run lint` — прошло;
- `npm run build` — production-сборка прошла;
- `npx prettier --check src/server/database.ts src/server/library-scanner.ts src/server/service.ts tests/playlist-sync.test.ts` — прошло;
- `git diff --check` — прошло.

Реальная библиотека Zenphone и UI вручную не проверялись; E2E и упаковка
установщика не запускались. Подтверждённые сценарии используют временные
библиотеки. Изменения не опубликованы и не влиты в основную копию.
