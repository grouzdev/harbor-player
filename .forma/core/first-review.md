# Первый обзор

**Установленные страницы — ещё не восстановленный контекст.**
Прочитай местные инструкции, [[core|ядро]] и выполни
[[update-state-map|обновление карты состояния]] целиком.
Не начинай с анкеты о каталогах и командах. Явные ограничения соблюдай.
Обзор охватывает существенные области всей репы, но не каждую строку.

Сначала объясни собственный предмет проекта, затем запиши понятные входы
и раскрытия по [[graph|правилам графа]]. Запуск обзора включает исправление
первого экрана; новая карточка в глубине не заменяет результат.
Не меняй приложение, не читай секреты и не обращайся к сети без разрешения.

Дополняй `index.md` только обоснованными результатами и ссылками.
Создавай короткие содержательные страницы по необходимости, не страницу на карточку.
Не копируй README и ADR и не создавай пустое оглавление ради шаблона.
Пиши по-русски; имена файлов — английские lower-kebab-case.
Детализация подсистем — отдельная задача. Дальше — [[workflow|рабочий цикл]].
