# Запись

Короткие связанные Markdown-страницы UTF-8. Одна страница — одна тема.
Содержимое — по-русски; имена файлов и каталогов — английские, lower-kebab-case.
В начале два свойства; дополнительных машинных полей в `forma/0.1` нет:

```text
---
id: project.overview
kind: concept
---
```

`id` уникален и сохраняется при переименовании. Значения — латинские буквы,
цифры, точка, дефис или подчёркивание, без кавычек.
Типы страниц: `core`, `specification`, `program`, `concept`, `scenario`,
`decisions`, `questions`, `source`, `implementation`.
`program` требует исполняемый блок, для обычного паспорта используй `concept`.
Статусы, основания и авторство пока записываем обычным видимым текстом.

Wiki-ссылка на страницу: `[[core]]`; на раздел: `[[core#Сначала понять]]`.
Имена должны быть однозначны внутри каталога страниц; допустим путь от его корня.
При переименовании обновляй ссылки. Ссылка сама по себе не означает «доказывает».
Внешние код и документы адресуй обычными Markdown-ссылками с указанием версии.
HTML и скрытые комментарии вне примеров запрещены.

## Исполняемый минимум

Ровно один блок `forma` на странице. Пример:

````text
```forma
язык forma/0.1
когда запускаем
  скажи "Привет!"
```
````

Поддерживается только `скажи "текст"` с отступом ровно в два пробела,
экранирования `\"`, `\\`, `\n`, `\r`, `\t`.
Пустые строки разрешены; хотя бы одно действие обязательно.
Другие команды и версии — ошибка; сначала проверяется весь сценарий.
Язык содержимого не меняет грамматику `forma/0.1`.
Текст не отправляется shell или модели. Обычные сценарии читает агент.

Проверка страниц проверяет `id`, типы, ссылки и исполняемый синтаксис,
но не истинность выводов, естественный язык текста или соблюдение [[core|ядра]] агентом.
